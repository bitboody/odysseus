Docker vs. Native Install

By default, Odysseus runs inside Docker: an isolated container that bundles the app together with the exact versions of every dependency it needs. This keeps Odysseus from conflicting with other software on your machine and gives you a consistent, reproducible environment on every platform.

A native install runs Odysseus directly on your system, using whatever Python, Node, and system libraries are already installed. It's usually faster to install since there's no container image to pull or build.

Downsides of a native install

  • No isolation — dependencies can conflict with other apps
  • You're responsible for keeping runtime versions compatible
  • Harder to fully clean up, since files are spread across the system
  • Platform-specific bugs are more likely to occur
  • Updates may require reinstalling dependencies by hand
  • Some features may not work correctly outside a Docker environment
